# Pinned per Intel's own guidance: newer transformers versions export models
# in a shape the NPU *static* pipeline doesn't recognize yet (fails with
# "Port for tensor name cache_position was not found" at inference time,
# even though the same export works fine on CPU/GPU). If you already ran
# `pip install -r requirements-openvino.txt` before this pin was added,
# reinstall (`pip install transformers==4.51.3`) and re-export any model
# you plan to use on NPU.
transformers==4.51.3
